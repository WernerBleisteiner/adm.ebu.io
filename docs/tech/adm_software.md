# ADM Related Software

## ADM Code Libraries

* [libadm](https://github.com/ebu/libadm) - C++ library for ADM generation and parsing.
* [libbw64](https://github.com/ebu/libbw64) - C++ library for handling BW64 files.
* [libear](https://github.com/ebu/libear) - C++ library for the EAR (EBU ADM Renderer).

## Tools that Support the ADM

* [EAR Production Suite](https://ear-production-suite.ebu.io/) - Extensions and VST3 plug-ins foe the REAPER DAW to support ADM authoring.
* [DaVinci Resolve](https://www.blackmagicdesign.com/uk/products/davinciresolve) - A DAW and video editor that support ADM export.
