# diffuse

The `diffuse` parameter appears in [`audioBlockFormat`](../audio_channel_format_objects.md#audioblockformat) only for the 'Objects' typeDefinition.

The `diffuse` value between 0.0 and 1.0 describes the diffuseness of a sound, where 0.0 (the default) is a direct non-diffuse sound, and 1.0 a completely diffuse sound.
